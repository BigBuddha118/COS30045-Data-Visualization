# Appliance Energy Consumption Website

A small multi-page website built for **COS30045 – Data Visualisation, Exercise 0.2**.

## Purpose
This project demonstrates:
- structuring a simple multi-page website using HTML
- consistent styling across pages using CSS
- basic interactivity with JavaScript (navigation highlighting, FAQ accordion)
- regular, meaningful commits to a GitHub repository

## Pages
- `index.html` – Home page with intro content and FAQ accordion
- `televisions.html` – Placeholder content on television energy usage
- `about.html` – About the project, including a Generative AI acknowledgement

## Folder Structure

## How to Run
Open `index.html` in a browser, or use the **Live Server** extension in VS Code
for automatic reload while editing.
